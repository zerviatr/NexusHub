# Project Map Güncelleme Kuralı

NexusHub projesinde her değişiklik sonrası `.agents/rules/nexushub-project-map.md` dosyasını güncelle.

Güncelleme gerektiren durumlar:
- Yeni dosya/modül/sayfa eklenmesi
- Dosya silinmesi veya taşınması
- Yeni IPC kanalı eklenmesi
- Yeni bağımlılık (npm paketi) eklenmesi
- Route değişiklikleri
- Design token değişiklikleri
- Mimari pattern değişiklikleri

Güncelleme gerektirmeyen durumlar:
- Mevcut dosyalarda bug fix
- CSS/stil tweakleri
- Mevcut fonksiyonlarda mantık değişikliği (API yüzeyi aynı kalıyorsa)
